Confidant · Architecture & trust boundary

Where can a client's words go?

Confidant transcribes a spoken recap on the clinician's own laptop, deletes the audio the moment the transcript exists, and drafts the note with a local model — every sentence is then checked against the transcript and refused if its words cannot be found. By default nothing clinical crosses the boundary: the only paths out are optional Sentry tracing, which carries stage, latency, token and cost metadata but never clinical text, and remote mode — off by default — which does send the transcript to an endpoint. The only path in is the one-time model download.

Self-contained figure: no CDN, no webfonts, no scripts, no external requests — it renders offline.
